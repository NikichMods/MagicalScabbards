## Инженерный gate

- Известный pawn writer `scabbard_on/off` меняет `bHiddenInGame`. Harness пишет только `bVisible` через `SetVisibility(value, false)` на одном pawn-компоненте за раз. Активный HUD, локальный pawn, stock cudgel, owner, identity, родитель, сокеты, asset и флаги проверяются перед скрытием. После каждой операции повторно разрешаются обе цели, held mesh и cudgel sheath, сверяются ожидаемое изменение и остальные флаги.
- Первая команда только читает baseline и ставит наблюдение. Перед первым скрытием каждой цели вызов `SetVisibility(true, false)` на уже видимом компоненте должен доставить собственные reflected pre/post и оставить все проверяемые флаги прежними. При отсутствии пары тест завершается до скрытия. Этот контроль не доказывает покрытие прямых native записей.
- Чужая reflected запись `bVisible`, включая same-value, передаёт владение и останавливает тест. Чужой `SetHiddenInGame` также останавливает тест, его значение сохраняется. Если собственная запись ещё доказана, откатывается только `bVisible` на том же живом компоненте. При смене поколения или неоднозначности — `CLEANUP_PENDING` и ручной выход из игры, без записи в новый объект. Наблюдение действует даже между постановкой STOP в очередь и cleanup.
- Любой целевой skill или смена режима, EndPlay, LoadMap, STOP либо 120 секунд от baseline завершают тест. EndPlay/LoadMap помечают старую цель непригодной для записи. Хуки снимаются, глобальные lifecycle callbacks и клавиши становятся инертны. 120 секунд — предел сеанса, автоматического таймера скрытия нет.
- Стабы проверили A/B без перекрытия, STOP при активном hide, same-value чужую запись при уже поставленном STOP, сохранение штатного hidden, подмену объекта, ошибочного владельца, EndPlay/LoadMap, отсутствующую доставку, частичный сбой, timeout и cleanup. Из каталога кандидата `lua stub.lua Scripts/main.lua`.

## Один сеанс после отдельного разрешения

1. При закрытой игре установить только этот кандидат. Запустить игру вручную, выбрать обычный уже убранный молот и включить ShadowPlay. Фиксированный ракурс сзади немного сбоку, чтобы были видны обе стороны поясницы. До конца теста оружие не вынимать.
2. **Ctrl+Alt+F7** последовательно выполняет пять команд. Сделать паузу для кадра после каждой: baseline → скрыть A → восстановить A → скрыть B → восстановить B и закончить. Ожидаемые отметки: `BASELINE`, `SETTER_VERIFIED` / `HIDDEN part=A`, `RESTORED part=A`, `SETTER_VERIFIED` / `HIDDEN part=B`, `RESTORED part=B` / `CLEANED`.
3. **Ctrl+Alt+F8** — STOP в любой момент. При активной маске это путь отката с `RESTORED` и `CLEANED`. При аномалии остановить тест, а при `CLEANUP_PENDING` выйти из игры вручную. Видео и сырой журнал остаются локально.

Решение о полном составе принимается после кадров и readback. Если A отвечает за крупный корпус, он дополняет подтверждённый `hilda_cudgel_sheath`. B включать в решение только при отдельном подтверждении, что его видимая геометрия входит в целевой комплект. Изолированные сравнения не проверяют совместное скрытие и не закрывают production gate.
