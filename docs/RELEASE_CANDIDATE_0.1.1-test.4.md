# MagicalScabbards 0.1.1-test.4 — универсальные искры исчезновения

**Status: NOT ACCEPTED FOR RELEASE.** Конкретный source commit и SHA-256 фиксируются Git manifest во время сборки, а не догадкой в тексте этого документа. Тестовый архив `0.1.1-test.3` и стабильная `v0.1.0` остаются неизменными.

## Объём

- Пользователь подтвердил визуал `test.3`, обычный перекат, следующую атаку и, дополнительно, работу искр после **холодного запуска без браузера**. Эти результаты относятся к предыдущему кандидату и не заменяют приёмку нового.
- Новый объём: VFX один раз перед исчезновением ножен для каждого подтверждённого stowed-окна **со всеми шестью семействами и допустимыми сочетаниями**. Сохраняется ранний запуск около 2900 ms, само скрытие после 3000 ms и полной повторной проверки. Досрочная вспышка при отменённом hide остаётся возможным ранее оговорённым косметическим компромиссом.
- Приняты фиксированные параметры: `scale 0.60`, `CustomTimeDilation 0.5`, `cutoff 1500 ms`. Свет, шаблон `stf01_spark`, `scabbard_b`, пороги и все правила hide/show не изменять. Отдельного магического эффекта появления в этом кандидате нет.
- Browser не устанавливается и не входит в ZIP; production не читает `ModRef`. Экспериментальные исходники `research/*` остаются в Git только как история, не как поставка.
- Для комплекта без посоха ресурс может оказаться нерезидентным. Предусмотрена **одна** синхронная игровая попытка `LoadAsset` точного stock `ParticleSystem` на session/map. Если его нет, VFX пропускается с `MISS`, но штатное скрытие/rollback продолжается.

## Автоматическая проверка

- Lua 5.4 frozen suites и актуальный `tests/test_runtime.lua` с независимым VFX-эмиттером, выбранными смешанными семействами, watchdog, отменой и fail-safe.
- Windows `Candidate checks` на точном коммите: `tools/test.py` и `tools/package.py`.
- ZIP должен содержать **шесть** `Scripts/*.lua`, в том числе `Scripts/vfx.lua`; `enabled.txt`, `manifest.json`, `README.md`, лицензию. Встроенный manifest содержит exact source SHA и SHA-256 всех payload.
- Категорически не переименовывать старую `0.1.1-test.3` и не подменять её байты. Не продвигать новый номер в stable без игры.
