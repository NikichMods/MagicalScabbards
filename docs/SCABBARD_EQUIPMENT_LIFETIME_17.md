## Наблюдение

Для нескольких последовательных смен нужно сохранить прежние отпечатки и сравнить их с актуальным набором. Старые журналы обрывают это сравнение на первом post. Новый observer сохраняет только строки имени/адреса, владельца и asset, без ссылок на UObject между событиями. Он собирает актуальное подмножество каталога на F7 и equipment post. В EndPlayPre и на необязательных K2 pre он перечитывает только уже известные компоненты соответствующего владельца. Новые строки добавляются при совпадении exact asset и доказанной привязке к локальной Хильде. `scabbard_a/b` учитываются в размере каталога, но жизненный цикл их масок повторно не проверяется. Предел 64 сохранённых строки на поколение явно сигнализируется через `overflow=true`. LoadMap и EndPlay Хильды сбрасывают поколение.

- `attached-local` → `resolved-outside-catalogue` → `attached-local` с прежним fingerprint и без наблюдённого разрыва даст свидетельство повторного прикрепления. После `lookup_gap=true` совпадение имени и адреса оставляет возможность переиспользования адреса. Обе проверки ограничены моментами снимков. `not-resolved` сам по себе не свидетельствует об уничтожении.
- Снимки `visible` и `hidden` сравниваются до ухода, после смены и после возврата. Совпадение значений показывает состояние в точках чтения. Между ними игра могла переписать тот же флаг, и сохранение произвольной маски из этого не следует.
- Для раннего release нужен воспроизводимый pre на том же маршруте, где прежняя цель ещё `attached-local`, `endplay=false` и `destroying=false`. Отдельный узкий тест затем должен подтвердить право на release и readback на живой цели. Если K2 pre не наблюдается, результат ограничивается отсутствием доставки через эти обёртки. Это не вывод об отсутствии прямых native вызовов.

**Один сеанс после отдельного разрешения.** С закрытой игрой оставить активным только этот кандидат MagicalScabbards. В игре **Ctrl+Alt+F7** включает наблюдение и снимает исходный набор. Сменить молот на парные клинки, через несколько секунд нажать **Ctrl+Alt+F7** для позднего снимка, затем сменить обратно на молот. Можно продолжить ещё одной сменой в удобном порядке. **Ctrl+Alt+F8** завершает с `CLEANED writes=0`. Достаточны исходный снимок, post после ухода, поздний снимок и post после обратной смены для двух прежних ресурсов. Если нужный путь не попал в журнал, результат неполный. Никаких масок в сеансе нет.

## Минимальная архитектура после проверки

Один каталог из 15 точных ресурсов определяет возможные цели, а допуск к записи требует актуального владельца, attachment и подтверждённой роли в stowed. В `SUPPRESSED` хранить отдельное владение маской на каждую допущенную identity. Один отменяемый таймер 2000 мс после подтверждённого Sheath перепроверяет фазу и поколение. Ранний draw переводит в `PASS-THROUGH` и снимает только принадлежащие моду маски. Смена экипировки обновляет каталог по событиям и сама таймер не запускает.

Для деталей самой Хильды можно переиспользовать проверенный синхронный release в EndPlayPre актора экипировки на этом маршруте. Для масок на уходящих акторах нужны ранний callback до detachment и начала завершения владельца либо отдельно доказанный независимый канал, который безопасно прекращает действие при выходе экземпляра из комплекта. До этого такие цели остаются без записи. Наблюдение даже полного выбытия на одном маршруте не разрешает оставлять маску на других маршрутах. Сохранение владения при штатных writers и защита held mesh остаются условиями расширения. Native-перехват в текущий шаг не входит.
