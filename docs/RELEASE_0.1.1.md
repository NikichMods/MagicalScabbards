## Стабилизация

Стабильные Lua-файлы сверяются с принятым тестовым коммитом. В `Scripts/main.lua` допустима только замена `local VERSION` на `0.1.1`. Исследовательский VFX Browser и его настройки остаются вне поставки. Искры играют перед исчезновением при подтверждённом stowed. В этом выпуске одна косметическая фаза, эффект появления не предусмотрен.

Лог содержит версию, целевой UE4SS, причину снятия маски, события активации и завершения эффекта и отказ при недоступном ресурсе. Детальные снимки опроса в обычной работе отключены. Известный `CLEANUP_PENDING owner-ended` наблюдался при закрытии процессов предыдущих кандидатов. Причина не установлена. Уклонение с переводом кинжалов в руку сохраняет обычный draw.

Пакет формируется из точного stable commit: `MagicalScabbards-0.1.1.zip`, `.zip.sha256` и `.manifest.json`. GitHub Actions проверяет Lua 5.4, source identity и checksum, затем публикует тег и Release `v0.1.1`. Исторические архивы неизменяемы.
