# MagicalScabbards 0.1.1 — подготовка выпуска

**Статус:** пользователь запросил выпуск текущей версии. Игровой gate универсального VFX ожидает подтверждения на шести семействах. Тег и Release публикуются после закрытия этого gate.

## Игровая база

Точный проверяемый кандидат: `0.1.1-test.5`, source `3e3a0aac306e3267f41b2e82163c536b0329302f`, ZIP SHA-256 `dd5327199c344b79e13a53743911fb9895c4bf43c31c711b43aac5e6b45863b0`.

- [Test.3](VFX_DESIGN_01.md#игровой-сеанс-test3) подтвердил обычный перекат, атаку после него и принятый вид Staff cast spark с параметрами 0,60 / 0,5 / 1,50 с и штатным цветом.
- [Test.4](RELEASE_CANDIDATE_0.1.1-test.4.md) расширил эффект исчезновения на все поддерживаемые семейства. Пользователь подтвердил холодный запуск. Полный охват искр по семействам остаётся открытым.
- [Test.5](RELEASE_CANDIDATE_0.1.1-test.5.md) подтвердил визуальное сохранение скрытия без повторной вспышки на переходе и появление ножен при вынимании оружия. Отдельной записи `draw-pre` в последнем сеансе нет.

## Стабилизация

Стабильные Lua-файлы сверяются с принятым тестовым коммитом. В `Scripts/main.lua` допустима только замена `local VERSION` на `0.1.1`. Исследовательский VFX Browser и его настройки остаются вне поставки. Искры играют перед исчезновением при подтверждённом stowed. В этом выпуске одна косметическая фаза, эффект появления не предусмотрен.

Лог содержит версию, целевой UE4SS, причину снятия маски, события активации и завершения эффекта и отказ при недоступном ресурсе. Детальные снимки опроса в обычной работе отключены. Известный `CLEANUP_PENDING owner-ended` наблюдался непосредственно при закрытии процесса; причина не установлена. Уклонение с фактическим переводом кинжалов в руку сохраняет обычный draw; талантовый вариант отдельно не подтверждён в игре.

После проверки игрового gate добавить точную строку принятого источника. Пакет формируется из точного stable commit: `MagicalScabbards-0.1.1.zip`, `.zip.sha256` и `.manifest.json`. GitHub Actions повторно проверяет Lua 5.4, source identity и checksum, затем публикует тег и Release `v0.1.1`. Исторические архивы неизменяемы.
