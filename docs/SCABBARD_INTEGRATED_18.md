## Покрытие

- Один runtime с `PASS-THROUGH` и `SUPPRESSED`. START сам не скрывает. Подтверждённый stock `EquipModeChange(Sheath)` post и штатная reflected пара ставят один отменяемый таймер 2000 мс. Expiry перепроверяет актуальный pawn, stock actor/root/held/sheath, отсутствие skill и набор допустимых идентичностей. Локальный `BeginDoSkill` pre отменяет таймер и синхронно отпускает доступные маски, а защёлка исключает поздний Sheath до InHand. Повторный Sheath заменяет ожидающий таймер. Боевой getter не используется.
- На событиях собирается любое подмножество 15 точных ресурсов. **Write-допуск ограничен проверенным маршрутом обычного молота и ролями шести компонентов из [Dynamic 13](SCABBARD_DYNAMIC_CUDGEL_13.md).** Количество присутствующих целей произвольное. Таблица доказанных ролей проверяет конкретные свойства владельца, компонент, сокет и режим, а одна политика работает для всех допущенных строк. Остальные ресурсы видны в диагностике. Остальные семейства и draw-маршруты пока не заявлены как поддержанные.
- У каждой маски собственная identity и reflected same-value probe, hide/release с pre/post и readback. Запись только `SetVisibility(value,false)` на допущенной цели. Штатный `bHiddenInGame` остаётся независимым. Отражённый конфликт на цели или распространяющем запись предке блокирует дальнейшую запись в затронутую маску. Прямые native writers могут быть невидимы для этого контроля.
- В EndPlayPre экипировки синхронно отпускаются доступные `scabbard_a/b` текущей Хильды по [EndPlay Release 16](SCABBARD_ENDPLAY_RELEASE_16.md). Для маски уходящего владельца нужны одновременно `Destroyed` и `IsActorBeingDestroyed()==true`, тогда логируется `RETIRED` без setter. Это **принятая экспериментальная гипотеза** о выбытии на основе [Lifetime 17](SCABBARD_EQUIPMENT_LIFETIME_17.md#игровой-сеанс-2026-11-08). До игрового прогона влияние активной маски на уходящий объект неизвестно. Иной или неизвестный исход оставляет маску в учёте с `CLEANUP_PENDING`. `RELEASED` относится только к записи с подтверждённым readback.
- После смены следующий game-thread refresh заново строит набор. Если прежний подтверждённый stowed-контекст сохранён, остаётся `SUPPRESSED`, проверяются сохранённые маски и подавляются новые допустимые компоненты без нового таймера. При замене stock-якоря или утрате контекста включается `PASS-THROUGH` с попыткой безопасного release на остальных целях. После возврата молота нужен новый подтверждённый переход Sheath. Reload отменяет таймер, освобождает доступные маски до смены поколения и исключает запись по старым данным. При недоступном HUD можно повторить F7 после его появления.
- STOP снимает подтверждённые маски, отменяет таймер и снимает reflected hooks. `CLEANED` требует пустого учёта неразрешённых масок. Отдельный счётчик `retired` сохраняет различие между retirement и rollback. Если остался `CLEANUP_PENDING`, новый START заблокирован, пока очистка не подтверждена. При незакрытой маске завершить игру без сохранения.

## Один свободный сеанс после отдельного разрешения

При закрытой игре установить этот Lua в `ue4ss/Mods/MagicalScabbardsIntegrated01/Scripts/main.lua` и оставить `enabled.txt` только у нового кандидата MagicalScabbards. Steam 1.09 / build 12996889, UE4.27, UE4SS 83330635. Загрузка проверяет конфликт клавиш.

1. При видимом игровом HUD нажать **Ctrl+Alt+F7**. С обычным молотом штатно вынуть и убрать оружие. Выждать примерно две секунды, проверить исчезновение убранного комплекта и повторить draw. Сделать один быстрый draw до истечения задержки и проверить, что старый таймер не скрывает комплект.
2. После очередного hide сменить молот на парные клинки. Проверить отсутствие видимого остатка и нормальный вид оружия в руках. Вернуть молот и выполнить новый draw/stow. Для других семейств ожидается штатная видимость с диагностикой. Дополнительные атаки и смены можно делать в удобном порядке.
3. Загрузить существующее сохранение, после появления HUD повторить один цикл с обычным молотом. Нажать **Ctrl+Alt+F8**. При `CLEANED` можно повторить START. Если исчезло оружие в руках, остался дубль, либо STOP сообщил `CLEANUP_PENDING`, завершить игру без сохранения.

Игровой gate — подтвердить автоматический hide/show, отсутствие позднего hide после отмены, поведение старого комплекта с активной маской при смене, отсутствие переноса маски на новые экземпляры и корректный STOP. Известный PASS двух деталей не требует отдельного повторного прогона.
