# MagicalScabbards 0.1.1-test.6 — проверка упрощения отсчёта

**Status: NOT ACCEPTED FOR RELEASE.** База — проверенный [test.5](RELEASE_CANDIDATE_0.1.1-test.5.md) из `3e3a0aac306e3267f41b2e82163c536b0329302f`.

`reconcile.lua` единолично определяет начало нового окна stowed и сообщает его для диагностического `WINDOW_START`. Путь активного скрытия в `main.lua` сохраняет проверку текущего комплекта, часов и владения. Удалена недостижимая ветка `kit-unsupported`: предыдущая ветка уже проверяет тот же `STOWED`. Пороги, VFX и обработка вынимания унаследованы из test.5.

В игре дождаться, пока ножны скроются, пробежать тот же переход, затем вынуть оружие. На переходе ожидается сохранение скрытия без новой вспышки. При вынимании ножны должны сразу появиться. Полная проверка семейств для релиза отслеживается отдельно.
