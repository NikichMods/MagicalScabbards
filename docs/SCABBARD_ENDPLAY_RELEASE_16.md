## Узкий опыт

[Universal 01](SCABBARD_UNIVERSAL_15.md#игровой-сеанс-2026-11-08) подтвердил старые привязки на входе в EndPlayPre. По post два из шести экземпляров были заменены. Из четырёх оставшихся взяты только два компонента самой Хильды, `scabbard_a/b`. Их визуальная роль и обратимость записи доказаны в [Dynamic 13](SCABBARD_DYNAMIC_CUDGEL_13.md). Прежний observer не может подтвердить setter в этом callback, а прежний write-test уходит в отложенную очистку и запрещает запись после retirement. Новый опыт меняет ровно границу release.

- Одно нажатие вручную ставит две маски при проверенном stock stowed обычного молота. Проверяются локальный pawn/HUD/anim, отдельный скрытый held mesh, точные assets, owner, parent и sockets двух целей. Для каждой сначала same-value проба и затем `SetVisibility(false,false)` с reflected pre/post и readback. `bHiddenInGame` не пишется. Ручная постановка нужна для эксперимента. Продуктовый переход после Sheath и 2000 мс остаются в [требованиях](REQUIREMENTS.md).
- Когда завершается один из известных акторов экипировки, release вызывается синхронно внутри его EndPlayPre. Обе цели принадлежат другому актору — текущей Хильде. Каждая независимо проходит повторную проверку поколения, идентичности и исходного флага, затем reflected pre/post и readback. Reflected конфликт на цели или на распространяющем запись предке делает владение недоказанным. При таком конфликте либо провале проверки цель пропускается с `CLEANUP_PENDING`. Прямые native записи в тот же флаг могут обходить отражённые хуки. Временное владение годится для ограниченного опыта и не закрывает production gate.
- Уходящие владельцы и все компоненты экипировки остаются под штатным управлением. В post обновляется каталог произвольного подмножества из 15, включая новые экземпляры, и для уходящего компонента фиксируются прежняя identity/доступность и сохранение attachment. `not-resolved` значит отсутствие того же экземпляра по прежней привязке, а не доказанное уничтожение. Если он больше не разрешается и визуально ничего не осталось, этот маршрут согласуется с уходом без rollback. Если прежний объект ещё прикреплён или повторно используется, автоматический отказ от отката для гипотетической маски рискован. Оба исхода измеряются при штатной видимости уходящего объекта.
- STOP, локальный skill и equipment post могут снять собственные маски как запасные границы. Если release случился там, результат EndPlayPre не засчитывается. LoadMap pre пытается снять только маски всё ещё валидного старого поколения и затем запрещает записи по нему. При EndPlay самого pawn generation сразу закрывается без записи. После reload снимок обновляется по доступному контексту или по повторному F7, без нового hide. При отказе очистки STOP оставляет запись `CLEANUP_PENDING`; новое вооружение опыта требует нового процесса.

Если синхронный release не подтвердится, простой контроль — снять маску по STOP перед сменой слота. Он даёт безопасный управляемый опыт и не покрывает автоматическую смену. Для автоматической схемы можно ограничить маску долгоживущими компонентами, если это приемлемо визуально, либо искать уже доступный более ранний сигнал. Для уходящих акторов не расширять запись, пока не установлены их фактическое выбытие или отдельный обратимый канал. Native-перехват и замена assets в этом опыте не нужны.

## Один игровой прогон после отдельного разрешения

1. При закрытой игре установить только этот кандидат MagicalScabbards. Войти с тем же набором и обычным молотом, штатно убрать оружие, выждать не менее двух секунд. **Ctrl+Alt+F7** — поставить две маски. Нужен `ARMED targets=2`.
2. Сразу выполнить ту же смену слота, что в Universal 01. До неё не атаковать. Ожидаются `EQUIPMENT_ENDPLAY`, две строки `RELEASED reason=equipment-endplay`, затем `CATALOGUE_SCAN stage=equipment-post` и `ENDING_TARGET_POST`. Посмотреть, вернулись ли обе детали и нет ли остатка уходящего комплекта. При отсутствии подтверждённого release либо неожиданной картине нажать STOP сразу.
3. После успешной смены загрузить уже существующее сохранение. Дождаться HUD и нажать **Ctrl+Alt+F7** для read-only refresh, если контекст ещё не обнаружен. **Ctrl+Alt+F8** — STOP, ожидается `CLEANED`. При `CLEANUP_PENDING` выйти без сохранения. Исходный игровой протокол не требует активной маски при reload, эта ветка покрыта офлайн.
