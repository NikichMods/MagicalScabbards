## Production gates

- Базовый hide/show и жизненный цикл F8: **принято** в наблюдавшемся объёме.
- Упаковка: `tools/package.py` формирует воспроизводимый ZIP из exact Git blobs, manifest с `source_commit` и SHA-256. На stable линии CI сверяет `Scripts/main.lua`, версию `v0.1.0`, архив, notes и checksum перед публикацией.
- Публичный релиз: GitHub Releases на теге `v0.1.0`, asset строго соответствующий tagged commit. Проверить фактическое завершение workflow и доступность файлов.
- Hot Lua reload, неподтверждённые конфигурации/хосты и автоматический rollback при shutdown с активной маской — не заявлять проверенными.

Исторический [план и отчёты](RESEARCH_PLAN.md) сохраняют детализацию инженерных решений. Production-код изменять в будущих версиях только по доказанному дефекту или согласованному улучшению.
