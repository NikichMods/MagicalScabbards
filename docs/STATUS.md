# MagicalScabbards — текущий статус

**2026-11-19 · v0.1.0 принята пользователем для первой стабильной публикации.** Исходный игровой кандидат `0.1.0-test.1` проверен в двух сеансах; исходная тестовая сборка неизменна. Для `v0.1.0` меняются только версия и release/packaging-метаданные. Точный опубликованный пакет определяется tagged source commit и manifest; проверять результат автоматической публикации в [GitHub Releases](https://github.com/NikichMods/MagicalScabbards/releases). [Релизный gate](RELEASE_0.1.0.md).

## Принятое поведение

Ножны и убранное в них оружие скрываются после 3000 мс непрерывно подтверждённого stowed; с начала draw мод отпускает собственное подавление. Не влияет на оружие в руках, браслеты на запястьях, объекты мира, игровые сохранения или боевые характеристики. Поддержано в наблюдавшихся сочетаниях всех шести семейств.

Загрузка карты, смена слотов, ранний draw и ручные F8 STOP/restart поддерживаются. Вариант с пустым соседним Bracer-слотом офлайн проверен и исключён из обязательной игровой приёмки как недоступный через штатное меню.

## Пределы и поддержка

- Подтверждённая среда: Asterigos Steam 1.09 / build 12996889; UE4SS 3.0.1-1181-g83330635; Windows x64. Другие окружения не объявлять проверенными.
- Hot unload Lua не поддерживается; заменить или удалить файлы только при закрытой игре. F8 для обычного выхода не требуется.
- Единственный `owner-ended` при завершении первого игрового сеанса имеет неизвестную причину. Второй сеанс подтвердил два полных `CLEANED`; автоматическая очистка при shutdown с активной маской не объявляется доказанной. Не открывать новую исследовательскую серию без воспроизводимого пользовательского дефекта.
- Временное появление ножен при смене через меню/Bracer допустимо. **VFX 01 в `dev/vfx-01` — доставка собственного Niagara BLOCKED на Windows cook.** Локальный UE4.27 Editor/cooker не найден. IoStore-инструмент доступен, регистрация уникального пакета ещё не проверена. Проба `LoadAsset` подготовлена, игровой запуск не выполнялся. Приоритет 2026-11-20 — исчезновение ножен в виде одной жёсткой области с одним распределённым эмиттером. Для исчезновения подготовлена [отдельная проба astral_missile_shoot](../research/stock-vfx-fade-01/README.md). Видимый запуск и исчезновение компонента к 1,603 с подтверждены. Длительность на экране и прерывание ещё не проверены. [Результат проверки](../research/custom-vfx-load-01/README.md#local-preflight-result) · [Дизайн VFX](VFX_DESIGN_01.md#принятое-упрощение-жёсткий-объект-и-собственная-система-частиц-2026-11-20).

## Источники принятия

На `dev/vfx-01` боевая проба `0.1.1-test.1` подтвердила автоматический запуск, три повтора и штатное завершение компонента. **Последующий просмотр полного пользовательского видео выявил визуальную проблему: 3/5, эффект похож на крупный синий дым/газ у пояса, выходит за контур ножен; художественная приёмка НЕ ПРОЙДЕНА.** **VFX Browser 01 принят как исследовательский инструмент:** 20 записей, в игре подтверждены экранная подпись и управление без модификаторов (F6 — назад, F7 — вперёд, F9 — повтор), 10 PLAY и 10 штатных SKIP; StaffRebalanceDev временно отключён с согласия пользователя ради конфликта F7. Пользователь выбрал **№02 `stf01_spark`** и при `scale=0.60` одобрил размер самих искр, **не** скорость/ширину разлёта и голубую засветку. По одноразовому runtime-осмотру модулей (`f6ec20a` → `17dc398`) у шаблона сферический StartLocation, StartSize 3–7, SizeScaleBySpeed, local vector field и отдельный ParticleModuleLight с BrightnessOverLife 20/RadiusScale 500; перечисленные значения не равны измеренным мировым скоростям или уровню освещения. Безопасный instance parameter для независимой коррекции разлёта/скорости при сохранении размера **не подтверждён**. Нельзя объявлять текущий шаблон подходящим для production-исчезновения. Следующий gate: ограниченно проверить альтернативный короткий stock spark с компактной траекторией и без света либо отдельный custom cooked VFX при появлении UE4.27 cooker; не менять shared asset/CDO и не повторять уже принятые тесты браузера. Исторический PASS ограничен механизмом, STOP с живым компонентом и exit-cleanup не доказаны. [Видеоотзыв и действие](VFX_DESIGN_01.md#визуальный-отзыв-2026-11-20--механика-pass-художественная-приёмка-не-пройдена).
