# Задание локальному Codex — статическое исследование ножен (research-only)

Работай в отдельном репозитории/checkout NikichMods/MagicalScabbards после фактической инициализации и проверки текущего Git-состояния. Если репозиторий ещё не создан на GitHub, сначала выполни bootstrap согласно NikichMods/DevRules/PROJECT_BOOTSTRAP.md (при наличии разрешённой аутентификации и доступа); не выдумывай URL/HEAD и не перезаписывай существующую папку. Прочитай актуальные DevRules `WORKING_RULES.md`, `ENGINEERING_RULES.md`, `GIT_WORKFLOW.md`, `CODEX_WORKFLOW.md`, `PROJECT_BOOTSTRAP.md`; затем локальные `AGENTS.md`, `docs/REQUIREMENTS.md`, `docs/STATUS.md`, `docs/RESEARCH_PLAN.md`, `docs/NO_SCABBARD_REFERENCE.md` и канонический `NikichMods/Asterigos-Research/docs/RESEARCH_INDEX.md` / `VERIFIED_RUNTIME.md`.

**Цель исследования:** выяснить, является ли отображаемая геометрия ножен Хильды отдельным компонентом, material section или частью общего SkeletalMesh, и что именно делает сторонний No Scabbard. В частности отделить ножны от оружия в руках и ресурсов `_use/_unuse`. Опирайся на 15 точных путей и SHA-256 в `docs/NO_SCABBARD_REFERENCE.md`, не переснимай уже подтверждённые сведения без причины.

**Сначала:** проверь реальную локальную установку Asterigos, пути/версии/game assets, наличие доступной копии присланного No Scabbard (восстанови её из пользователя/предыдущей локальной папки при необходимости; не предполагай путь), разрешённые инструменты UAsset/IoStore, права на чтение. Сравни original vs replacement лишь для точных 15 ресурсов, извлекая необходимые безопасные метаданные, без брутфорса всей игры. Используй существующие CUE4Parse/UHT выгрузки, если они достаточны; новые дампы только при конкретном evidence-gap.

**Не делай:** production патчей, install/runtime write probes, новых версий/релизов, перепаковки чужих ассетов, удаления или переименования пользовательских модов, загрузки любых proprietary/сторонних игровых бинарников/дампов в GitHub. Установленные пакеты и EXE только читать. До отдельного разрешения не запускать и не менять игру.

**Результат:** краткий статический отчёт в `docs/SCABBARD_STATIC_RESEARCH_01.md` с baseline, проверенными объектами, точными путями, типами ресурсов и сравнением, статусом каждого вывода (verified vs hypothesis), альтернативами `component visibility` / `section visibility` / `asset replacement`, рисками lifecycle, критериями следующего узкого runtime-probe и reviewable `READY/BLOCKED`. Переносимые принятые game facts с доказательствами продвинь в Asterigos-Research по его правилам, без дублирования статуса мода.

Работай на ветке `research/scabbard-static-01`, сохрани исходное рабочее состояние, сделай только документальные коммиты и push в GitHub при доступе. В ответе сообщи repo/branch/commit SHA/push, 3–6 строк выводов и неустранённый blocker. Если создание GitHub remote требует пользователя, сообщи **один** точный UI-шаг и не называй проект опубликованным.
