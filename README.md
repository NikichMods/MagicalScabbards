# MagicalScabbards

**Asterigos: Curse of the Stars** — проект самостоятельного мода NikichMods: ножны Хильды скрыты вне боя и появляются при входе в бой. Визуальная цель — небольшая магическая материализация/дематериализация, без изменения игровых характеристик.

> **Статус: bootstrap / исследование. Мод ещё не реализован, установочного пакета и проверенной версии нет.**

## Целевое поведение

- **Бой:** ножны отображаются в штатном месте крепления, с исходным масштабом и материалами.
- **Вне боя:** ножны незаметны; после выхода из боя предполагается небольшая задержка, чтобы избежать мерцания при кратковременных сменах состояния. Точная длительность подлежит визуальной приёмке.
- **Магия:** деликатные искры у пояса при реальном появлении/исчезновении — желаемая вторая фаза после надёжного переключения геометрии, а не основание менять механику оружия.
- **Без побочных эффектов:** не менять одежду, отображение оружия в руках, боевые характеристики, коллизии, анимации, звук, сохранения и другие моды.

**Исходные доказательства:** пользователь предоставил отдельный архив `No Scabbard`; его IoStore-индекс содержит 15 именованных ресурсов оружейной группы. Имена позволяют сузить исследование, **не доказывают**, что все 15 относятся непосредственно к ножнам или могут быть скрыты безопасно.
