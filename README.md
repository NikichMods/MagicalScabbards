# MagicalScabbards

Самостоятельный NikichMods-мод для **Asterigos: Curse of the Stars**: **ножны и размещённое в них оружие** появляются, когда Хильда начинает **доставать оружие**, остаются видимыми пока оно в руках и во время анимации убирания, а исчезают **через 2 секунды после `EquipModeChange(Sheath)`**, если оружие всё ещё полностью убрано.

> **Статус:** исследование. Production gate: BLOCKED; исполняемого мода, установочной сборки и принятой версии ещё нет.

## Принятая механика

| Стадия оружия | Видимость ножен |
| --- | --- |
| Полностью убрано | скрыты ножны и оружие внутри |
| Начало вынимания | показать **немедленно**, отменить ожидающий hide |
| В руках | видимы |
| Идёт убирание | видимы |
| `EquipModeChange(Sheath)` | запустить **один** таймер на 2 секунды; пока видимы |
| Через 2 секунды | скрыть весь убранный комплект **только если всё ещё stowed** |

**В бою и вне боя правило одинаково.** Изменение концепции принято 2026-11-06; прежняя привязка к battle state и задержка после боя отменены. Принятое уточнение: **2-секундная задержка после Sheath**, а не точный конец анимации. Старые таймеры инвалидируются при новом draw, смене экипировки и жизненного цикла. Наличие безопасной маски с откатом ещё не подтверждено.

Желаемый второй этап — короткий неброский магический эффект появления/исчезновения. Не менять механику оружия, исходные анимации, видимость активного оружия в руках, одежду, освещение, HUD и сохранения.

## Текущие технические сведения

- [Статический отчёт](https://github.com/NikichMods/MagicalScabbards/blob/9f360eba1dd8eb33eba5e0b6de075c278a664e10/docs/SCABBARD_STATIC_RESEARCH_01.md): сторонний No Scabbard заменяет 15 штатных ресурсов пустыми SkeletalMesh; это исследовательский ориентир, но не пригодный механизм обратимого hide/show.
- [Runtime-отчёт](https://github.com/NikichMods/MagicalScabbards/blob/3d60cf7ce8725f4fa0efa4b2d589a1ac24c73064/docs/SCABBARD_RUNTIME_RESEARCH_01.md): подтверждены владельцы, пересоздание объектов при загрузке и независимость фактического положения оружия от battle getter.
- [Последний игровой результат](https://github.com/NikichMods/MagicalScabbards/blob/a8a76622888d0257e08e8442ffd80cdd5d93453b/docs/SCABBARD_COMBINED_VISIBILITY_10.md): на обычном молоте **PASS** для совместного скрытия трёх деталей и ручного отката. Принадлежность оставшихся медальона/пластин неизвестна; полноценные переходы draw/stow ещё не приняты. Ближайшая задача — [адресная идентификация остатка](docs/RESEARCH_PLAN.md) с учётом всех замен No Scabbard.
