# MagicalScabbards

Самостоятельный NikichMods-мод для **Asterigos: Curse of the Stars**: **ножны и размещённое в них оружие** появляются, когда Хильда начинает **доставать оружие**, остаются видимыми пока оно в руках и во время анимации убирания, а исчезают **после полного убирания**.

> **Статус:** исследование. Production gate: BLOCKED; исполняемого мода, установочной сборки и принятой версии ещё нет.

## Принятая механика

| Стадия оружия | Видимость ножен |
| --- | --- |
| Полностью убрано | скрыты ножны и оружие внутри |
| Начало вынимания | показать |
| В руках | видимы |
| Идёт убирание | видимы до конца анимации |
| Полностью убрано | скрыть |

**В бою и вне боя правило одинаково.** Изменение концепции принято 2026-11-06; прежняя привязка к battle state и задержка после боя отменены.

Желаемый второй этап — короткий неброский магический эффект появления/исчезновения. Не менять механику оружия, исходные анимации, видимость активного оружия в руках, одежду, освещение, HUD и сохранения.

## Текущие технические сведения

- [Статический отчёт](https://github.com/NikichMods/MagicalScabbards/blob/9f360eba1dd8eb33eba5e0b6de075c278a664e10/docs/SCABBARD_STATIC_RESEARCH_01.md): No Scabbard заменяет 15 оригинальных ресурсов пустыми SkeletalMesh; у pawn есть отдельные scabbard_a/b, у экипировки — составные ресурсы с геометрией оружия. При подтверждении, что это убранный комплект, скрытие целого компонента допустимо.
- [Runtime-отчёт](https://github.com/NikichMods/MagicalScabbards/blob/3d60cf7ce8725f4fa0efa4b2d589a1ac24c73064/docs/SCABBARD_RUNTIME_RESEARCH_01.md): подтверждены актуальные владельцы, пересоздание объектов при загрузке и несовпадение боевого статуса с положением оружия. Семантические стадии draw/stow и безопасное подавление видимости ещё не доказаны.
